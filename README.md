# Expense Tracker

A modern web application to track personal expenses and manage spending efficiently.

## Features
- Add new expenses with name, amount, and category
- View all expenses in a clean table
- Delete expenses
- Category-based organization with color tags
- Total spending displayed at the top
- Preloaded sample data

## Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- SQLite Database

## Project Structure
- app.py – backend logic
- templates/ – HTML files
- static/ – CSS styling

## How to Run
1. Open the project in Replit
2. Run the application
3. Use the interface to add and manage expenses

## Demo
This project includes sample expense data for demonstration purposes.
